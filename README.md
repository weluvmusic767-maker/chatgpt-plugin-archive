# ChatGPT Plugin Archive

A version-controlled historical archive of ChatGPT plugin
catalog information.

## Purpose

This repository preserves plugin information even when plugins
disappear from the ChatGPT plugin directory.

The archive tracks:

- Plugin names
- Categories
- ChatGPT plugin pages
- External websites
- Plugin identifiers
- Capabilities
- Access information
- Device requirements
- Research depth
- Historical snapshots
- Changes over time
- Removed plugins

## Data Sources

Primary sources include:

- ChatGPT Plugin Directory
- Firecrawl extraction of ChatGPT category pages
- Individual ChatGPT plugin detail pages
- Optional external documentation and research

## Repository Structure

- categories/ = current category inventories
- snapshots/ = point-in-time inventories
- changes/ = machine-readable changes
- reports/ = human-readable reports
- scripts/ = automation scripts
- metadata/ = archive configuration and schemas

## Important Rule

Plugins are NOT deleted merely because they disappear from one
live category listing.

Absence is an investigation trigger.

A plugin should only be marked as confirmed removed after
verification.

## Data Philosophy

The machine-readable archive should remain useful without
depending on a proprietary AI provider.

Notion may provide a human-facing interface, but this repository
is intended to remain the durable historical data source.

## Temporary Files

Files named .gitkeep are temporary Git placeholder files.

Remove them from a directory once real tracked files exist
there.
